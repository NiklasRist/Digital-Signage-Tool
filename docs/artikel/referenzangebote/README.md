## Warum diese fünf

- **Preisspanne 0 – 19,95 €.** Ohne einen hohen Preis prüft das Kriterium „Preis-Hierarchie"
  (AD 14) nichts.
- **Vier Produkte, ein Service.** Der Obstkorb trägt keinen Preis, sondern eine Bedingung — daran
  zeigt sich, ob das Layout auch ohne Zahl funktioniert.
- **Zwei Hochformat-Bilder** (3 und 5) und **drei quadratische**: das prüft die Einpassung, ohne dass
  jemand dafür etwas einstellen muss.

## Was hier absichtlich NICHT steht

- **Keine Vorlage, keine Farbe, keine Effekte.** Das ist die Designarbeit, die gemessen wird.
- **Keine Produkt-URLs.** Der Abruf ist FA-27 und noch nicht gebaut (#469).
