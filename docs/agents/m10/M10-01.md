### Issue M10-01: [shared] Effekt-Satz, Grenzen und die reine Rechnung

## Ziel (in einem Satz)
Ein Effekt-Satz am Aktions-Datensatz wird an **einer** Stelle geprüft und in einen reinen,
DOM-freien **Zustand je Bild** übersetzt – die einzige Quelle für Vorschau und Render.

## Modul & Datei
- Modul: geteilter Bereich (Renderer **und** Main lesen die Typen)
- Dateien:
  - `src/shared/effekte.ts` (neu)
  - `src/shared/contracts/aktion.ts` (die drei Typen + das optionale Feld `Aktion.effekte`)
- Vertrag: Technisches Konzept **9.16.1, 9.16.2, 9.16.7**, **9.8.2** (Quelle der Wahrheit)
- Anforderung: Anforderungsdokument **4.10**, **FA-25**

## Warum das im Gesamtsystem wichtig ist
Bewegung darf **nicht** an zwei Stellen gerechnet werden. Rechnet der Main anders als der Renderer,
laufen Vorschau und Video auseinander – genau die Zusage, um die es FA-25 geht. Diese Datei ist
deshalb **rein**: kein DOM, keine Zeit, kein Zufall; sie liefert zu einem Bildindex einen Zustand.

## Signatur (verbindlich – NICHT ändern)
```ts
export interface FensterEffekt {
  staerke: number        // 0–100 (% der Vorgabe; 0 = aus)
  vonSekunden: number    // 0 … dauer
  bisSekunden: number    // > von, ≤ dauer
}

export interface SchleifenEffekt {
  staerke: number        // 0–100 (% der Vorgabe; 0 = aus)
}

export interface EffektSatz {
  kenBurns?:        FensterEffekt
  textEinblendung?: FensterEffekt
  preisPop?:        FensterEffekt
  glanzSweep?:      FensterEffekt
  preisZaehlt?:     FensterEffekt
  bildReveal?:      FensterEffekt
  puls?:            FensterEffekt
  zoomAtmen?:       SchleifenEffekt
  drift?:           SchleifenEffekt
  parallax?:        SchleifenEffekt
}

export interface EffektZustand {
  zoomBild: number
  zoomHintergrund: number
  versatzBildX: number
  versatzBildY: number
  versatzHintergrundX: number
  versatzHintergrundY: number
  textAlpha: number
  textVersatzY: number
  preisSkala: number
  zaehlAnteil: number | null      // 0…1 beim Hochzählen, sonst null
  glanzFortschritt: number | null // 0…1, null = aus
  revealAnteil: number            // 0 = verdeckt, 1 = ganz da
  pulsSkala: number
}

export const EFFEKT_GRENZEN: {
  bilderProSekunde: number
  schleifeBilder: number
  staerke: { min: number; max: number }
  fensterSekunden: { min: number; max: number }
  maxEindeutigeBilder: number
}

export const RUHE_ZUSTAND: EffektZustand

export function normalisiereEffekte(
  effekte: EffektSatz | null | undefined,
  dauerSekunden: number,
): EffektSatz | null

export function effektZustand(
  effekte: EffektSatz | null | undefined,
  bild: number,
  bilderGesamt: number,
): EffektZustand
```

## Eingang → Ausgang
| Eingang | Bedeutung | Grenzen/Validierung |
|---|---|---|
| `effekte` | Effekt-Satz der Aktion | `null`/`undefined` → **Ruhezustand**; unbekannte Felder werden ignoriert |
| `dauerSekunden` | Dauer des Segments | 8–45 s (9.11.4); Fenster werden auf `0 … dauer` geklemmt |
| `bild` | Bildindex im Segment | `0 … bilderGesamt − 1`; außerhalb → auf den Rand geklemmt |
| `bilderGesamt` | `dauer × 30` | `≤ 0` → Ruhezustand |

Ausgang bei Erfolg: `EffektZustand` – immer vollständig, nie `null`.
Ausgang bei Fehler: keiner; die Funktion **wirft nicht** (Normalisierung ist Sache von
`normalisiereEffekte`).

## Verbindliche Invarianten (wörtlich – Verletzung = Issue nicht erfüllt)
- „**Fehlt es, ist alles wie heute** – ein Bestandsprojekt ändert sein Aussehen nicht." (TK 9.16.1)
- „Ein vorhandener Eintrag heißt **an**; `staerke: 0` heißt **aus** und darf **keinen** Frame
  erzeugen." (TK 9.16.1)
- „**Vertrag sind die Endpunkte, die Nahtlosigkeit und die Monotonie – nicht einzelne
  Zwischenwerte.**" (TK 9.16.2)
- „Ein Fenster endet **exakt im Ruhezustand**, sonst springt das Bild an seiner Grenze." (TK 9.16.2)
- „`bilderGesamt = dauer × 30`" (TK 9.16.2)
- „**Alle Fenster werden vorher auf ganze Frames gerundet** (`Math.round(sekunde × 30)`, geklemmt
  auf `0 … bilderGesamt`) – die Rechnung selbst kennt keine Sekunden mehr." (TK 9.16.2)

## Fehlerpfade (vollständig)
| Situation | Verhalten |
|---|---|
| `effekte` fehlt / `null` | `RUHE_ZUSTAND` |
| `staerke` außerhalb 0–100 | begrenzt; `0` fällt weg |
| `von` ≥ `bis` | Fenster wird verworfen (kein Effekt) |
| Fenster länger als 3 s | auf 3 s gekürzt |
| Fenster beginnt nach dem Segmentende | verworfen |
| unbekannter Effektname | ignoriert, **keine** Meldung |
| `bilderGesamt ≤ 0` | `RUHE_ZUSTAND` |
