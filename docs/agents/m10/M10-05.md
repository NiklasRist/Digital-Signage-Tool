### Issue M10-05: [action-editor] Die Gruppe „Effekte" – zehn Schalter, ein Entwurf, ein Schreibvorgang

## Ziel (in einem Satz)
Im Aktions-Editor lassen sich die zehn Effekte **einzeln** an- und abschalten, mit Stärke und Fenster –
und alles landet wie jedes andere Feld im Entwurf.

## Modul & Datei
- Modul: `action-editor` (Renderer)
- Datei: `src/renderer/action-editor/effekt-gruppe.tsx` (neu), eingebunden in `index.tsx`
- Vertrag: Technisches Konzept **9.16.6**, **9.8.6**
- Anforderung: Anforderungsdokument **4.10**, **FA-25**

## Warum das im Gesamtsystem wichtig ist
Ohne Bedienung gibt es keine Effekte. Die Gruppe ist bewusst **eine** Liste von Schaltern, kein Paket:
Der Nutzer soll „nur Ken Burns" wählen können, ohne sieben andere mitzunehmen.

## Signatur (verbindlich – NICHT ändern)
```ts
export interface EffektGruppeProps {
  entwurf: AktionsInhalt
  /** Setzt den GANZEN Satz – der Entwurf ist die einzige Wahrheit (9.8.6). */
  aufAendern: (effekte: EffektSatz | null) => void
}

export function EffektGruppe(props: EffektGruppeProps): JSX.Element
```

## Eingang → Ausgang
| Eingang | Bedeutung | Grenzen/Validierung |
|---|---|---|
| `entwurf.effekte` | aktueller Satz | fehlt → alle Schalter aus |
| `aufAendern` | schreibt den Satz in den Entwurf | **kein** IPC, **kein** Schreiben (das macht der Abschluss) |

Ausgang bei Erfolg: neuer `EffektSatz` im Entwurf; `null`, wenn kein Effekt mehr an ist.
Ausgang bei Fehler: keiner – die Grenzen klemmt `normalisiereEffekte` (M10-01).

  Fenster-Effekten zusätzlich Beginn und Ende in Sekunden." (TK 9.16.6)

## Fehlerpfade (vollständig)
| Situation | Verhalten |
|---|---|
| letzter Schalter aus | `aufAendern(null)` – das Feld verschwindet, `project.json` wächst nicht |
| Stärke auf 0 gezogen | Eintrag bleibt, wirkt nicht (M10-01 verwirft ihn beim Rechnen) |
| Fenster-Ende ≤ Beginn | Feld zeigt den Fehler, übernommen wird der geklemmte Wert |
| Fenster > 3 s | auf 3 s geklemmt, mit Hinweis |
| Preis fehlt / ist keine Zahl | Schalter „Preis-Pop"/„Preis zählt hoch" sichtbar, mit Hinweis „ohne Preis wirkungslos" |
| kein Bild gewählt | Schalter „Bild-Reveal"/„Ken Burns" sichtbar, mit Hinweis |
| Vorlage ist ein **Band** | die ganze Gruppe ist **ausgeblendet** (TK 9.16.3: Band bleibt still) |
