### Issue M10-04: [action-editor] Die Vorschau zeigt die Bewegung – Editor schleift, preview-player zeichnet den Frame

## Ziel (in einem Satz)
Wer eine Aktion gestaltet, **sieht** den Effekt laufen – und die Sequenz-Vorschau zeigt an jeder
Abspielposition genau das Bild, das auch gerendert wird.

## Modul & Datei
- Modul: `action-editor` (Renderer), mitbenutzt: `preview-player`
- Dateien:
  - `src/renderer/action-editor/live-vorschau.ts`
  - `src/renderer/action-editor/index.tsx` (die Schleife, dort wo die Vorschau steht)
  - `src/renderer/preview-player/segment.tsx`
- Vertrag: Technisches Konzept **9.16.6**, **9.9.2**
- Anforderung: Anforderungsdokument **4.10**, **FA-25**

## Warum das im Gesamtsystem wichtig ist
Ein Effekt, den man erst nach dem Rendern sieht, ist im Editor nicht gestaltbar. Die Vorschau ist die
Stelle, an der „wirkt wie Werbung" entschieden wird – und sie muss **dieselbe** Rechnung benutzen wie
der Render, sonst ist sie eine Behauptung.

## Signatur (verbindlich – NICHT ändern)
```ts
// live-vorschau.ts
export function zeichneVorschau(
  aktion: AktionsInhalt,
  vorlage: Vorlage,
  marke: Marke,
  zustand?: EffektZustand,
): SegmentBild

// preview-player/segment.tsx
export interface SegmentProps {
  aktion: Aktion
  vorlage: Vorlage
  marke: Marke
  x?: number
  y?: number
  /** Segment-Bild an dieser Abspielposition (0 … dauer×30−1). Fehlt: Ruhebild. */
  bild?: number
}
```

## Eingang → Ausgang
| Eingang | Bedeutung | Grenzen/Validierung |
|---|---|---|
| `zustand` (Editor) | Zustand des angezeigten Bildes | fehlt → Ruhebild (wie heute) |
| `bild` (preview-player) | Bildindex im Segment | außerhalb → auf den Rand geklemmt |

Ausgang bei Erfolg: sichtbares Canvas, das sich mit ~30 Bildern/s ändert.
Ausgang bei Fehler: wie heute (keine Schriften → es wird nicht gezeichnet).

## Fehlerpfade (vollständig)
| Situation | Verhalten |
|---|---|
| Ansicht wird geschlossen | Schleife **stoppt** (`cancelAnimationFrame`) – keine Waise |
| Segment ohne Effekte | Ruhebild; die Schleife darf gar nicht erst starten |
| Schriften fehlen | es wird nicht gezeichnet (heute schon so) |
| `bild` außerhalb des Segments | auf den Rand geklemmt, **keine** Meldung |
