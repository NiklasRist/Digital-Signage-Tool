## Ziel (in einem Satz)
Kaputte Elemente werden farblich markiert (rot/gelb), damit der Nutzer Probleme sieht, bevor er auf einen Button klickt.

## Modul & Datei
- Modul: `composer` (Renderer)
- Datei: `src/renderer/composer/fehler-markierung.tsx`
- Vertrag: Technisches Konzept **9.7.5** (Quelle der Wahrheit)
- Prozess/Speicher: P3

## Warum das im Gesamtsystem wichtig ist
Die Logik für die Kaputt-Erkennung ist bereits implementiert (`kaputt-erkennung.ts`), aber es gibt keine visuelle Markierung in der UI. Der Nutzer sieht nicht, dass ein Element kaputt ist, bevor er auf einen Button klickt.

## Signatur (verbindlich – NICHT ändern)
```ts
export function markiereKaputteElemente(liste: Listenelement[], projekt: Project): Map<string, 'rot' | 'gelb'>
```

## Eingang → Ausgang
| Eingang | Bedeutung | Grenzen/Validierung |
|---|---|---|
| `liste` | Wiedergabeliste | Array von `Listenelement` |
| `projekt` | Projekt | muss geladen sein |

Ausgang bei Erfolg: Map mit Element-ID → Farbe.
Ausgang bei Fehler: Keine (reine UI-Anzeige).
