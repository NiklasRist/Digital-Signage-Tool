## Warum das im Gesamtsystem wichtig ist
In DaVinci Resolve, CapCut sind Kontextmenüs essenziell für effizientes Arbeiten. Der Nutzer klickt mit der rechten Maustaste auf ein Element und sieht alle relevanten Aktionen.

## Signatur (verbindlich – NICHT ändern)
```ts
export function KontextMenue({ element, position }: { element: Listenelement; position: { x: number; y: number } }): JSX.Element
```

## Eingang → Ausgang
| Eingang | Bedeutung | Grenzen/Validierung |
|---|---|---|
| `element` | Listenelement | muss geladen sein |
| `position` | Mausposition | `{ x: number; y: number }` |

Ausgang bei Erfolg: Kontextmenü wird angezeigt.
Ausgang bei Fehler: Keine (reine UI-Anzeige).
