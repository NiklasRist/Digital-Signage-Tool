## Ziel (in einem Satz)
Eine horizontale Timeline zeigt Dauer, Reihenfolge und Inhalt aller Elemente auf einen Blick.

## Modul & Datei
- Modul: `composer` (Renderer)
- Datei: `src/renderer/composer/zeitleiste.tsx`
- Vertrag: Technisches Konzept **9.7** (Quelle der Wahrheit)
- Prozess/Speicher: P3

## Warum das im Gesamtsystem wichtig ist
Die Liste ist ein Text-Verzeichnis. Der Nutzer sieht nicht, wie lang ein Clip ist oder wo er beginnt/endet. Eine Timeline zeigt auf einen Blick: Dauer (Breite), Reihenfolge (Position) und Inhalt (Thumbnails).

## Signatur (verbindlich – NICHT ändern)
```ts
export function Zeitleiste({ liste, projekt }: { liste: Listenelement[]; projekt: Project }): JSX.Element
```

## Eingang → Ausgang
| Eingang | Bedeutung | Grenzen/Validierung |
|---|---|---|
| `liste` | Wiedergabeliste | Array von `Listenelement` |
| `projekt` | Projekt | muss geladen sein |

Ausgang bei Erfolg: Timeline wird angezeigt.
Ausgang bei Fehler: Keine (reine UI-Anzeige).

## Verbindliche Invarianten (wörtlich – Verletzung = Issue nicht erfüllt)
- „Die Reihenfolge ist die Array-Reihenfolge von `liste` – es gibt **kein** separates `position`-Feld." (TK 9.11.3)
- „Angezeigte Reihenfolge = gerenderte Reihenfolge – keine versteckte Sortierung." (TK 9.7.4)

## Fehlerpfade (vollständig)
| Situation | Code | Verhalten |
|---|---|---|
| Liste ist leer | – | Leere Timeline anzeigen |
| Element hat unbekannte Dauer | – | Element mit Standard-Breite anzeigen |
