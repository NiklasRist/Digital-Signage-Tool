## Ziel (in einem Satz)
Die Vorschau zeigt die Wiedergabeliste in Echtzeit, damit der Nutzer sieht, was seine Änderung bewirkt.

## Modul & Datei
- Modul: `preview-player` (Renderer)
- Datei: `src/renderer/preview-player/index.ts`
- Vertrag: Technisches Konzept **9.9** (Quelle der Wahrheit)
- Prozess/Speicher: P5

## Warum das im Gesamtsystem wichtig ist
Der Nutzer muss sehen, was seine Änderung bewirkt. Ohne Live-Vorschau ist ein Trimmen ein Blindflug. Die Vorschau ist ein Kernbestandteil der Hauptbetriebsart (FA-20).

## Signatur (verbindlich – NICHT ändern)
```ts
export function zeigeVorschau(liste: Listenelement[], projekt: Project): JSX.Element
```

## Eingang → Ausgang
| Eingang | Bedeutung | Grenzen/Validierung |
|---|---|---|
| `liste` | Wiedergabeliste | Array von `Listenelement` |
| `projekt` | Projekt | muss geladen sein |

Ausgang bei Erfolg: Vorschau wird angezeigt.
Ausgang bei Fehler: Keine (reine UI-Anzeige).

## Verbindliche Invarianten (wörtlich – Verletzung = Issue nicht erfüllt)
- „Die Vorschau läuft vollständig im Renderer, ohne `ffmpeg`." (TK 8)
- „Eine 16:9-Bühne (1920×1080 herunterskaliert) spielt die Liste der Reihe nach ab." (TK 8)
- „Medienzugriff ausschließlich über `media://` (9.5.7) – der `preview-player` sieht **nie** absolute Pfade." (TK 9.9.2)

## Fehlerpfade (vollständig)
| Situation | Code | Verhalten |
|---|---|---|
| Liste ist leer | – | Leere Vorschau anzeigen |
| Medium fehlt | – | Platzhalter anzeigen |
