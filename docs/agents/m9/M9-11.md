## Ziel (in einem Satz)
Vollbild-Vorschau-Modus für die Vorschau, um das Endergebnis auf dem Ziel-Bildschirm zu prüfen.

## Modul & Datei
- Modul: `preview-player` (Renderer)
- Datei: `src/renderer/preview-player/vollbild.tsx`
- Vertrag: Technisches Konzept **9.9** (Quelle der Wahrheit)
- Prozess/Speicher: P5

## Warum das im Gesamtsystem wichtig ist
In DaVinci Resolve, CapCut gibt es einen Vollbild-Vorschau-Modus (z. B. für TV-Ausgabe). Der Nutzer muss sehen, wie das Endergebnis auf dem Ziel-Bildschirm aussieht.

## Signatur (verbindlich – NICHT ändern)
```ts
export function VollbildVorschau({ liste, projekt }: { liste: Listenelement[]; projekt: Project }): JSX.Element
```

## Eingang → Ausgang
| Eingang | Bedeutung | Grenzen/Validierung |
|---|---|---|
| `liste` | Wiedergabeliste | Array von `Listenelement` |
| `projekt` | Projekt | muss geladen sein |

Ausgang bei Erfolg: Vollbild-Vorschau wird angezeigt.
Ausgang bei Fehler: Keine (reine UI-Anzeige).

## Verbindliche Invarianten (wörtlich – Verletzung = Issue nicht erfüllt)
- „Die Vorschau läuft vollständig im Renderer, ohne `ffmpeg`." (TK 8)
- „Eine 16:9-Bühne (1920×1080 herunterskaliert) spielt die Liste der Reihe nach ab." (TK 8)

## Fehlerpfade (vollständig)
| Situation | Code | Verhalten |
|---|---|---|
| Liste ist leer | – | Leere Vorschau anzeigen |
