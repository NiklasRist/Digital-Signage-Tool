## Warum das im Gesamtsystem wichtig ist
In Canva, Clipchamp sieht der Nutzer auf einen Blick: Gesamtdauer, Anzahl der Elemente, Verhältnis Video zu Segmenten. Das hilft, die Wiedergabeliste zu verwalten.

## Signatur (verbindlich – NICHT ändern)
```ts
export function Statistik({ liste }: { liste: Listenelement[] }): JSX.Element
```

## Eingang → Ausgang
| Eingang | Bedeutung | Grenzen/Validierung |
|---|---|---|
| `liste` | Wiedergabeliste | Array von `Listenelement` |

Ausgang bei Erfolg: Statistiken werden angezeigt.
Ausgang bei Fehler: Keine (reine UI-Anzeige).

## Verbindliche Invarianten (wörtlich – Verletzung = Issue nicht erfüllt)
